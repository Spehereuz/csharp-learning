# Topic 02 — Data Types

## Завдання
Написати програму яка:

1. Виводить таблицю основних числових типів у форматі:
  Type         Min                    Max                    Size
  int          -2147483648            2147483647             4 bytes
  long         ...                    ...                    8 bytes
  float        ...                    ...                    4 bytes
  double       ...                    ...                    8 bytes
  decimal      ...                    ...                    16 bytes
3. Оголошує змінну типу `double` зі значенням `1_234_567.891` і виводить її
4. Оголошує змінну типу `int` через binary literal що дорівнює числу `26` і виводить її у трьох форматах — decimal, binary, hex
5. Демонструє що `int` і `System.Int32` це одне і те саме — вивести `MaxValue` обох і порівняти їх

## Теми
- Типи даних та їх відповідники в CTS
- `MinValue` / `MaxValue` числових типів
- `sizeof()`
- Digit separators
- Binary literals
- Форматування чисел
