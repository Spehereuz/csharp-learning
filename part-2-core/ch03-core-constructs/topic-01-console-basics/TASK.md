# Topic 01 — Console Basics

## Завдання
Написати консольну програму яка:
1. Приймає з командного рядка два числа як аргументи
2. Виводить їх суму, різницю, добуток і частку — кожне на новому рядку, у форматі: 10 + 5 = 15
3. Якщо аргументів передано не два — виводить повідомлення про помилку і повертає код помилки 1 операційній системі
4. Якщо другий аргумент дорівнює 0 — ділення не виконується, замість цього виводить відповідне повідомлення
Використати Console.ForegroundColor щоб вивести результати зеленим кольором, а повідомлення про помилку — червоним.
